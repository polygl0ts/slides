# Slides

**Public** repository that contains all slides that were given for polygl0ts presentations. All presentations must be saved both in editable form and as a pdf.

## Folder structure

We make a per-academic-semester distinction to make it easy to differentiate what is relevant and what isn't, and because beginner tutorials are regiven at the start of each semester since new people tend to join at these times.

Follow this template:

+ 2025-2026-spring
  + fridays
    + lesson0
      + what_are_ctfs.tex
      + what_are_ctfs.pdf
      + Makefile
    + lesson1
      + intro2pwn.pptx
      + intro2pwn.pdf
    + ...
    + OUTLINKS.md
  + ...
+ ...
